# Seb's Book Catch (Wii U)

A small KiddReads game. Move Seb with the left stick or D-pad, catch the falling books, press A to start. Three misses ends the round.

Build runs on GitHub Actions (devkitPPC + wut) and uploads `seb.rpx`. Copy `wiiu/apps/seb/` to the SD card for the Homebrew Launcher or Aroma.
